# 🔐 Skill Booster Cybersecurity Tasks

This repository contains hands-on cybersecurity challenges designed for beginners who want to build practical skills in ethical hacking and penetration testing.
---

## 📌 What You Will Learn

- Steganography 
- Hash Cracking techniques
- Packet Analysis using Wireshark
- Basic enumeration and analysis skills

---

## 🧠 Difficulty Level

Beginner → Intermediate

---

## 🛠️ Tools You May Need

- Kali Linux
- Wireshark
- CyberChef
- John the Ripper / Hashcat
- Steghide / Binwalk
- Note: Some challenges may require additional tools depending on the approach.
